# অধ্যায় ১ – পাইথন দিয়ে প্রথম প্রোগ্রাম : অনুশীলনীর সমাধান

আগে নিজে চেষ্টা করতে হবে। এখানকার সমাধান একমাত্র সমাধান নয়, নিজের প্রোগ্রাম ভিন্নভাবে লেখা হলেও ঠিকঠাক কাজ করলেই হলো।

## অনুশীলনী ১

নিচের প্রোগ্রামটি রান করলে কী আউটপুট আসবে, সেটি আগে খাতায় লিখতে হবে। তারপর প্রোগ্রামটি রান করে মিলিয়ে দেখতে হবে।

```python
print("Python")
print("Rules")
```

**উত্তর :** দুই লাইনে প্রিন্ট হবে, প্রথম লাইনে Python, দ্বিতীয় লাইনে Rules। প্রতিটি `print()` নতুন লাইনে প্রিন্ট করে।

## অনুশীলনী ২

