# অধ্যায় ১৪ – খুদে প্রজেক্ট : অনুশীলনীর সমাধান

আগে নিজে চেষ্টা করতে হবে। এখানকার সমাধান একমাত্র সমাধান নয়, নিজের প্রোগ্রাম ভিন্নভাবে লেখা হলেও ঠিকঠাক কাজ করলেই হলো।

## অনুশীলনী ১

ওপরের প্রোগ্রামে `size = random.randint(5, 25)`–এর বদলে বিন্দুর আকার একটি লিস্ট থেকে নিতে হবে। `sizes = [5, 10, 20]` লিস্ট তৈরি করে লিখতে হবে `size = sizes[random.randint(0, len(sizes) - 1)]`। এখানে `len(sizes) - 1` কেন লিখলাম? যদি `random.randint(0, len(sizes))` লিখতাম, তাহলে কী সমস্যা হতো? আর একই কাজ `random.choice()` দিয়ে কীভাবে করা যায়?

**উত্তর :** `randint()` দুই প্রান্তের সংখ্যাই দিতে পারে। লিস্টে উপাদান 3টি, তাই ইনডেক্স 0, 1 আর 2। `random.randint(0, len(sizes))` লিখলে মাঝে মাঝে 3 আসবে, আর `sizes[3]` চাইলে `IndexError` হবে। এরকম ভুল খুব বিপজ্জনক, কারণ প্রোগ্রামটি প্রতিবার নয়, কেবল মাঝে মাঝে ক্র্যাশ করে। `random.choice(sizes)` লিখলে ইনডেক্স নিয়ে চিন্তাই করতে হয় না।
