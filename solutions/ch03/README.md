## অনুশীলনী ৪

নিচের প্রোগ্রামটি রান করলে কী প্রিন্ট হবে? আগে খাতায় লিখে তারপর রান করে মিলিয়ে দেখতে হবে।

```python
x = 10
if x > 5:
    print("A")
elif x > 8:
    print("B")
else:
    print("C")
```

**উত্তর :** শুধু A প্রিন্ট হবে। `x > 5` সত্য, তাই প্রথম ব্লকটি চলে। `if`–`elif`–`else`–এ যে শর্তটি প্রথমে সত্য হয়, কেবল সেই ব্লকটিই চলে, বাকিগুলো আর পরীক্ষাই করা হয় না। তাই `x > 8` সত্য হলেও B প্রিন্ট হয় না।
